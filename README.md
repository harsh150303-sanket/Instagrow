# InstaGrow (Android, Kotlin)

InstaGrow is an offline Instagram growth assistant MVP.

## Features
- Splash screen with 2-second auto-navigation
- Home dashboard with 4 generators
- Caption Generator (category + tone)
- Hashtag Generator (20 hashtags from local datasets)
- Bio Generator (business type + style)
- Best Time to Post suggestions
- RecyclerView-based result lists with copy-to-clipboard
- Dark theme Material UI

## Tech
- Kotlin
- Activity-based navigation
- Min SDK 21
- No backend/API
